        Sobre este catálogo

        Este projeto foi desenvolvido como trabalho individual da disciplina SCOM, com o objetivo de aplicar boas práticas de estrutura semântica, responsividade, acessibilidade e desempenho em uma interface web construída com HTML5 e CSS3 puros.

        CineArquivo — projeto acadêmico, SCOM 2026. Pôsteres e dados de filmes: TMDB. Este produto usa a API do TMDB, mas não é endossado nem certificado por ele. Voltar ao topo
